# Wizard flow

Generated by `tools/flowgen/generate_flows.py` (the source of the app's step lists). Do not edit by hand.

Order and wording follow the checklists in `docs/checklists/`. The wizard runs on a machine where Windows is already installed; it starts at checklist section 1 (First boot).

- **Automatic**: the wizard does it after you confirm (🔒 = typed confirmation / security-reducing).
- **Manual**: you do it, then confirm.
- **Check**: read-only verification.
- **Check** column: the test that tells whether the step is already done (`audit:` = the script's `-Audit` mode). **Check this machine** runs every check, marks what is done and jumps to what is missing.
- **After**: the step is only needed when that step was run now (e.g. a restart after PostInstall); when the earlier step was found already done, this one is marked not needed.
